# Правила проекта

3D-хоррор от первого лица на Unity. Личный проект-подарок.

## Порядок чтения

1. Этот файл.
2. `.agents/global-agent-rules/AGENTS.md` — универсальный контракт.
3. `.agents/global-agent-rules/code-style.md` — стиль C#.
4. `.agents/global-agent-rules/unity-ui-toolkit-interface-pipeline.md` —
   обязателен для любой работы над интерфейсом.
5. `gamedesign/CONCEPT.md` — что за игра.
6. `gamedesign/DEVELOPMENT_PLAN.md` — канонический чеклист стадий.

## Факты проекта

- Unity **6000.5.10f1**, URP, Forward+.
- Ввод: Input System. Интерфейс: UI Toolkit. Сборка геометрии: ProBuilder.
- Сборки: `unity -batchmode -quit -projectPath . -logFile -`.
- Ассембли: `Game.Runtime`, `Game.Editor`, `Game.Tests.EditMode`,
  `Game.Tests.PlayMode`.
- Сохранение: обычный JSON в `Application.persistentDataPath/save.json`,
  с полем `version`.

## Переопределения общих правил

- **Весь личный контент — вне git.** Фотографии, голосовые, переписка,
  настоящие подписи осколков и названия мест живут в `private/`.
  Код знает только идентификаторы. Это не удобство, а требование:
  репозиторий публичный.
- **`*.md` в `.gitignore`.** Документация раскрывает сюрприз целиком.
  Правило унаследовано из `imaO0O/game-rpg` осознанно.
- **Ничего не строится кодом в рантайме.** Меши, свет, партиклы,
  коллайдеры — в префабах и сценах. Предыдущая реализация собирала всё
  процедурно в `_ready()`, и визуал стало невозможно итерировать.
- **У скримера два обязательных такта.** `Strike()` без `Resolve()` —
  не скример этой игры. Разрядка идёт игроку в субтитр и звук,
  а не в консоль.

## Чего в проекте нет и не надо

2D-ветки, метроидвании, способностей, скрытых стен, системы диалогов,
уровней по городам. Города — содержание осколков, а не локации.
